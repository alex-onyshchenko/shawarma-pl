# 🌯 Шаурма на Вугіллі — Telegram Mini App + KDS (Kitchen Display System)

Повна екосистема онлайн-замовлень та автоматизації кухні для точки швидкого харчування. Складається з двох взаємопов'язаних частин:
1. **Клієнтський Telegram Mini App (TMA)** — темна тема, вибір страв, кастомізація інгредієнтів через Bottom Sheet, кошик, доставка/самовивіз.
2. **Термінал Кухаря (KDS — Kitchen Display System)** — PWA-застосунок для планшета на стіні/підставці перед кухарем з Kanban-дошкою, таймерами затримки, величезним контрастним шрифтом та кольоровим кодуванням модифікаторів.

---

## 🌐 Адреси запущених сервісів

| Застосунок | Порт | Призначення |
| :--- | :--- | :--- |
| **📱 Telegram Mini App** | **[http://localhost:3000](http://localhost:3000)** | Інтерфейс клієнта у Telegram (або браузері) |
| **👨‍🍳 Термінал Кухаря (KDS)** | **[http://localhost:3001](http://localhost:3001)** | Інтерфейс для Android-планшета на кухні |

---

## 👨‍🍳 Особливості Терміналу Кухаря (KDS на порті 3001)

1. **Орієнтація на апаратну частину (Android-планшет у Кіоск-режимі)**:
   - **Screen Wake Lock API**: екран не гасне під час зміни.
   - **Повноекранний режим (Full-Screen Kiosk)**: кнопка розгортання на весь екран для приховування адресного рядка браузера.
   - **Великі шрифти та висока контрастність**: інформація без зусиль зчитується з відстані 1–2 метрів у гарячому цеху.

2. **Канбан-дошка з 3 колонок**:
   - **«Нові (Очікують)»** (синій колір, лічильник черги).
   - **«Готуються»** (вогняний помаранчевий колір).
   - **«Готові на видачу»** (зелений колір).

3. **Кольорове кодування модифікаторів (Критично важливо для швидкості)**:
   - **Зелений бейдж (`+`)**: додані інгредієнти (*+ Сир Чеддер*, *+ Халапеньйо*, *+ Подвійне м'ясо*).
   - **Яскраво-червоний бейдж (`✕`)**: прибрані інгредієнти (*- Без цибулі*, *- Без часникового соусу*), щоб кухар не поклав їх за звичкою!
   - **Помаранчеві/червоні бейджі**: тип лаваша та рівень гостроти.
   - **Жовтий блок уваги**: особливі коментарі клієнта до страви.

4. **Живий таймер замовлення та тривога затримки**:
   - Біля кожного чека в реальному часі йде відлік часу з моменту оформлення.
   - Якщо замовлення готується **понад 10 хвилин** — картка та таймер стають тривожно-жовтими.
   - При затримці **понад 15 хвилин** — картка пульсує червоним кольором.

5. **Звукові сповіщення (Web Audio API)**:
   - Приємний ресторанний дзвіночок при надходженні нового замовлення.
   - Звуковий клік при переміщенні чека.
   - Можливість вимкнути звук кнопкою в шапці.

6. **Керування в 1 клік (One-Tap Control)**:
   - Кухар просто тапає по картці (навіть у рукавичках), і вона миттєво переходить у наступну колонку.
   - Є кнопка скасування/повернення назад, якщо випадково натиснули не той чек.
   - Кнопка **«+ Тестове замовлення»** для швидкого тестування нових чеків.
   - Архів виданих замовлень за зміну.

## 🛠️ Команди для запуску

```bash
# Запуск клієнтського Telegram Mini App (порт 3000):
npm run dev

# Запуск Терміналу Кухаря KDS (порт 3001):
npm run dev:kds

# Збірка обох застосунків:
npm run build && npx vite build --config vite.kds.config.js
```
