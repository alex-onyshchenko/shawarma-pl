# 🌯 Шаурма на Вугіллі — Telegram Mini App + KDS (Синхронізовані в реальному часі)

Повна екосистема онлайн-замовлень та автоматизації кухні, де **клієнтський застосунок** та **планшет кухаря** синхронізовані у реальному часі через **Server-Sent Events (SSE)** та REST API.

---

## 🌐 Схема портів та адрес

| Сервіс | Порт | Призначення |
| :--- | :--- | :--- |
| **📱 Telegram Mini App** | **[http://localhost:3000](http://localhost:3000)** | Інтерфейс замовлення для клієнта (TMA) |
| **👨‍🍳 Термінал Кухаря (KDS)** | **[http://localhost:3001](http://localhost:3001)** | Планшет кухаря на стіні (Канбан-дошка) |
| **📡 Сервер синхронізації** | **[http://localhost:3002](http://localhost:3002)** | Real-Time SSE брокер та REST API замовлень |

---

## ⚡ Як працює синхронізація у реальному часі

1. **Клієнт робить замовлення** на `http://localhost:3000`:
   - Натискає «Оплатити через Telegram» у кошику.
   - Замовлення миттєво відправляється на сервер синхронізації (`POST /api/orders`).
2. **Планшет кухаря (KDS)** на `http://localhost:3001`:
   - **Миттєво (0 мс затримки)** отримує подію через SSE-потік.
   - Лунає **аудіо-дзвінок чека** (`Ding-dong!`).
   - Спалахує банер: `Нове замовлення #1044!`.
   - Чек з'являється у колонці **«НОВІ (ОЧІКУЮТЬ)»** з таймером, що тікає.
3. **Кухар тапає по чеку (статус `cooking`)**:
   - Чек переходить у колонку **«ГОТУЮТЬСЯ»**.
   - Статус транслюється клієнту: у Telegram Mini App крок `2. Смажиться на вугіллі` спалахує вогником!
4. **Кухар тапає «Готово» (статус `ready`)**:
   - Чек переходить у колонку **«ГОТОВІ НА ВИДАЧУ»**.
   - У клієнта екран оновлюється: вибухає додаткове конфетті і статус змінюється на `🎉 Готово до видачі!`.
5. **Кухар тапає «Видати» (статус `archived`)**:
   - Замовлення переміщується до архіву зміни.
   - Клієнт отримує сповіщення `✅ Замовлення видано. Смачного!`.

---

## 🚀 Команди запуску

```bash
# 1. Запуск сервера синхронізації (порт 3002)
npm run server

# 2. Запуск клієнтського Telegram Mini App (порт 3000)
npm run dev

# 3. Запуск планшета кухаря KDS (порт 3001)
npm run dev:kds
```
