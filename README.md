# 🌯 Шаурма на Вугіллі — Telegram Mini App (Web App)

Сучасний прототип інтернет-магазину та меню у форматі **Telegram Mini App (TMA)** з темною темою, анімаціями, кастомізацією інгредієнтів (Bottom Sheet), кошиком, вибором доставки/самовивозу та імітацією оплати через Telegram.

---

## ✨ Реалізовані можливості

1. **Дизайн та естетика Telegram Mini App**:
   - Темна тема в стилістиці Telegram WebApp (глибокий чорний `#09090b` та акцентний помаранчевий `#f97316`).
   - Нативний Telegram Header з кнопкою закриття/назад, верифікованим бейджем бота `✓` та системним меню `⋮`.
   - Режим попереднього перегляду: автоматична рамка смартфона (iPhone frame) для тестування на комп'ютері та перемикання на повний екран.
   - Інтеграція з Telegram WebApp SDK (`window.Telegram.WebApp`), тактильний зворотний зв'язок (Haptic Feedback) та звукові мікрокліки у звичайному браузері.

2. **Меню та категорії**:
   - Горизонтальний скрол категорій: *Шаурма*, *Комбо*, *Снеки*, *Напої*, *Соуси*.
   - Швидкий інтерактивний пошук за назвою або інгредієнтами.
   - Бейджі страв: *Хіт 🔥*, *Топ ⭐*, *Гостре 🌶️*, *Веган 🌱*, *Знижка -15%*.
   - Індикатор кількості товару в кошику безпосередньо на карточці.

3. **Модальне вікно кастомізації (Bottom Sheet)**:
   - Вибір лаваша (звичайний, сирний, шпинатний).
   - Рівень гостроти (не гостра, пікантна, гостра, вогонь 🔥).
   - Додавання інгредієнтів (подвійне м'ясо, чеддер, халапеньйо, бекон тощо) з підрахунком вартості на льоту.
   - Вилучення інгредієнтів з рецепта з візуальним закресленням.
   - Спеціальні побажання для кухаря.
   - Лічильник кількості з динамічною ціною.

4. **Оформлення замовлення (Checkout)**:
   - Деталізований список страв з переліком модифікаторів.
   - Перемикач **Самовивіз (-10%)** або **Кур'єрська доставка**.
   - Вибір пунктів видачі у Києві з часом очікування.
   - Промокоди (наприклад: `LAVASH10` або `VUHILLYA`).
   - Перемикач серветок та приладів.
   - Способи оплати (Telegram Pay, картка, при отриманні).

5. **Підтвердження та трекінг**:
   - Салют з конфетті (`canvas-confetti`).
   - Імітація push-сповіщення від бота `@ShawarmaCoalBot`.
   - Живий трекер етапів приготування (Прийнято ➔ Смажиться на вугіллі ➔ Готово до видачі).

---

## 🚀 Запуск проєкту

### 1. Запуск сервера розробки
```bash
npm run dev
```
Застосунок буде доступний за адресою: **http://localhost:3000**

### 2. Збірка для продакшну
```bash
npm run build
```

---

## 📱 Запуск всередині Telegram

Щоб протестувати застосунок безпосередньо у своєму Telegram клієнті:
1. Запустіть тунель для локального порту, наприклад через ngrok або cloudflare tunnel:
   ```bash
   npx cloudflared tunnel --url http://localhost:3000
   ```
2. Створіть бота в [@BotFather](https://t.me/BotFather) та створіть Web App кнопку через команду `/newapp` або `/setmenubutton`.
3. Вкажіть отриману HTTPS-адресу — застосунок автоматично підхопить профіль користувача, native haptics та розгорнеться на весь екран!
