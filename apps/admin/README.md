# Shawarma Admin

Самостоятельная React/Vite админ-панель, порт 3004. Node.js 24.

```bash
npm ci
npm run dev
npm run build
npm run preview
```

API проксируется на `http://127.0.0.1:3002`; другой адрес задаётся через
`SYNC_API_TARGET` в `.env`. Для сессионных cookie нужен same-origin proxy,
сохраняющий Host вместе с портом. Vite и nginx-конфиги уже настроены.

Вход — существующий `ADMIN_TOKEN` Sync. Ключ вводится только при входе;
браузер получает HttpOnly cookie на 8 часов. Ключ не хранится в localStorage.

Одна демо-точка активна. Новые точки создаются неактивными, их нельзя
активировать в MVP. Можно менять меню, расписание, наличие и настройки;
просматривать заказы и журнал. Фото позиции задаётся URL, загрузка файлов
в этой версии не предусмотрена.

Dockerfile собирает только этот каталог. nginx ожидает Sync как `sync:3002`.
