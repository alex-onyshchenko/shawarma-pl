# Shawarma Analytics

Самостійний React/Vite-застосунок, порт `3003`. Потрібен Node.js 24.
Цей каталог можна скопіювати та використовувати без решти репозиторію.

```bash
npm ci
npm run dev
npm run build
npm run preview
```

За замовчуванням `/api` проксіюється до `http://127.0.0.1:3002`.
Налаштування — у `.env.example`: `SYNC_API_TARGET` для dev/preview proxy,
`VITE_SYNC_API_URL` для публічної адреси REST і SSE, без `/api` у кінці.
Порожній `VITE_SYNC_API_URL` використовує same-origin `/api`.
Vite вбудовує `VITE_*` у збірку; зміна потребує повторної збірки.
У production налаштуйте reverse proxy `/api` або HTTPS-адресу API.

Dockerfile збирає цей каталог незалежно. Наданий nginx-конфіг очікує Sync
за адресою `http://sync:3002` у контейнерній мережі та підтримує SSE.
Для іншого розміщення API підмонтуйте власний nginx-конфіг.

## Звіти про продажі

Вкладка «Звіт»: останні 7, 21 або 30 днів (кнопка «1 місяць»),
ставка комісії 0–100% з точністю до двох десяткових знаків, повна виписка
й PDF. Авторизацію наразі вимкнено за рішенням власника. Нових env не потрібно.
Production: https://shawarma-pl-1zc9.vercel.app/

Дані й PDF надходять із `GET /api/analytics/report`. Враховуються тільки
видані замовлення поточної точки (`archived`), без скасованих і незавершених.
Нові продажі фільтруються за `issuedAt`; старі без цього поля — за `createdAt`,
із відповідною приміткою. Період — ковзне вікно до поточного моменту; час
відображається у часовому поясі точки. Комісія рахується в копійках по кожному
чеку, потім підсумовується. Виписка не обмежена останніми 50 чеками.
