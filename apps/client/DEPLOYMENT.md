# Клієнт → Vercel → Telegram Mini App

Клієнт — статичний Vite-сайт. Sync — окремий Node.js 24 процес із SSE та SQLite на постійному диску. Поточний Sync не переноситься у Vercel Functions: він потребує довготривалого процесу та постійного сховища. Наразі публічного Sync URL ще немає, сайт не опублікований.

## 1. Підготувати Sync

Розмістіть `services/sync` на сервері з Node.js 24 або через наявний Docker Compose. Налаштуйте HTTPS, постійний диск для SQLite та приватний `ADMIN_TOKEN`. Збережіть поточну базу, якщо потрібні налаштовані меню й точка. HTTPS-проксі має пропускати SSE `/api/events` без буферизації. Перевірте `https://SYNC_HOST/api/health`.

Для клієнта використовується прямий доступ до API: REST і SSE йдуть на одну адресу Sync. Поточний публічний API підтримує CORS. Не додавайте `/api` до значення змінної — клієнт додає цей префікс самостійно. Не використовуйте localhost або Docker-ім'я `sync` у публічній конфігурації.

Перед публічним прийомом реальних замовлень потрібне окреме посилення доступу: зараз KDS-операції (статуси замовлень, керування кафе, ручні замовлення, очищення) не захищені авторизацією, а стрічка замовлень спільна. При публікації Sync їх необхідно обмежити для працівників, а клієнту віддавати лише власні замовлення. Це підготовка MVP-фронтенду, не реалізація захисту публічного backend.

## 2. Налаштувати Vercel

Імпортуйте Git-репозиторій у Vercel:

| Поле | Значення |
| --- | --- |
| Root Directory | `apps/client` |
| Framework Preset | Vite |
| Install Command | `npm ci` |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Environment Variable | `VITE_SYNC_API_URL=https://SYNC_HOST` |

Додайте змінну для Production та Preview. Вона публічна й вбудовується у JavaScript під час збірки: жодних токенів або паролів сюди не додавати. Після зміни адреси виконайте Redeploy. Збірка на Vercel навмисно завершується помилкою без коректного HTTPS origin Sync, щоб не опублікувати клієнт із неробочим `/api`.

`npm run dev` завантажує `.env.dev`, `npm run build` — `.env.prod` (Vite mode `prod`). Шаблони — `.env.dev.example` і `.env.prod.example`; приватні локальні файли не комітяться. На Vercel значення задаються в Environment Variables та мають пріоритет над файлом.

`vercel.json` містить Vite-збірку та SPA fallback. Docker і локальний Vite зберігають свій `/api` proxy; для них нова змінна не обов'язкова.

## 3. Підключити Telegram

Після успішного HTTPS-деплою відкрийте @BotFather → `/mybots` → потрібний бот → Bot Settings → Menu Button → Configure menu button. Вкажіть текст «Замовити» та production URL клієнта, наприклад `https://YOUR_PROJECT.vercel.app`. Альтернатива — серверний Bot API `setChatMenuButton` з `type: web_app`. За потреби налаштуйте Main Mini App у BotFather для кнопки запуску в профілі бота.

SDK уже підключений перед кодом застосунку. Клієнт викликає ready/expand, задає темний фон, підтримує Telegram BackButton та haptic feedback. У звичайному браузері він працює як мобільний сайт без фальшивого профілю користувача, рамки телефона чи панелі симулятора.

Дані `initDataUnsafe` використовуються лише як необов'язкове ім'я для відображення, а не як авторизація. Для захищеної ідентифікації й персональних замовлень наступним кроком потрібно передавати `initData` на сервер і перевіряти підпис та строк дії. Токен бота зберігається тільки на сервері. Оплата при отриманні та імітація повідомлень залишаються поточною поведінкою MVP.

## 4. Перевірити перед підключенням користувачів

- Відкрити сайт на телефоні й у Telegram Android/iOS: меню перше, без рамки та горизонтального скролу; низ кошика не перекривається системною панеллю.
- Перевірити фото трьох шаурм, розміри, піджарку, кошик і оформлення при отриманні.
- Зачинити кафе/увімкнути перерву через KDS: клієнт бачить статус і не додає товари; відчинити — кнопки відновлюються.
- Оформити тестове замовлення, підтвердити на KDS, перевірити оновлення через SSE та резервне опитування.
- Перевірити Telegram «Назад» із кошика/підтвердження та повторне відкриття на головному меню.

Офіційні джерела: [Vercel configuration](https://vercel.com/docs/project-configuration/vercel-json), [Telegram Mini Apps](https://core.telegram.org/bots/webapps).
