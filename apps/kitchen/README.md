# Shawarma Kitchen

Самостійний React/Vite-застосунок, порт `3001`. Потрібен Node.js 24.
Цей каталог можна скопіювати та використовувати без решти репозиторію.

```bash
npm ci
npm run dev
npm run build
npm run preview
```

За замовчуванням `/api` проксіюється до `http://127.0.0.1:3002`.
Налаштування — у `.env.example`: `SYNC_API_TARGET` для dev/preview proxy,
`VITE_SYNC_API_URL` для публічної адреси REST і SSE, без `/api` у кінці.
Порожній `VITE_SYNC_API_URL` використовує same-origin `/api`.
Vite вбудовує `VITE_*` у збірку; зміна потребує повторної збірки.
У production налаштуйте reverse proxy `/api` або HTTPS-адресу API.

Dockerfile збирає цей каталог незалежно. Наданий nginx-конфіг очікує Sync
за адресою `http://sync:3002` у контейнерній мережі та підтримує SSE.
Для іншого розміщення API підмонтуйте власний nginx-конфіг.

Для замовлень у колонці «Нові» доступне скасування з необов’язковим коментарем
(до 500 символів) і підтвердженням у діалозі. Дія — хрестик угорі картки. Після видачі клієнту скасування недоступне. Історія та причина зберігаються у Sync; порожній коментар не надсилає повідомлення; заповнений надсилається клієнту в Telegram, якщо сповіщення дозволені.

Термінал показує лише активні замовлення у трьох колонках. Кнопки й вікна
архіву немає; видані та скасовані замовлення зберігаються в базі Sync.

Для готового неоплаченого замовлення є дія «Клієнт не прийшов» із
підтвердженням безстрокового обмеження на готівку для клієнта Telegram.
Номер для дзвінків відображається у картці. Кухонний API поки відкритий
за рішенням власника; ручні замовлення звільнені від клієнтських лімітів.

Час видачі на картці — кнопка редактора: +5/+10 хв або довільна майбутня дата й час у часовому поясі точки. Окремого підтвердження часу немає; «Почати готувати» підтверджує його автоматично. Кожна зміна часу надсилає сповіщення; повторний запит не дублює його. Таймер ховається після спливання часу, без попереджень про запізнення. Ім’я клієнта — зліва, телефон — справа. Секція додатків і плашка «На зараз» на картці не показуються; піджарки лаваша немає.

У «Готуються» можна повернути замовлення до «Нових», у «Готові на видачу» — до «Готуються». Повернення зберігає час видачі й не надсилає повторних повідомлень клієнту.
