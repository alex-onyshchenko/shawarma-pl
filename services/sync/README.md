# Shawarma Sync

Автономний Node.js HTTP/SSE-сервіс без npm-залежностей. Потрібен Node.js 24.
Не імпортує код фронтендів і не роздає їхні статичні файли.

```bash
npm ci
npm start
npm run dev
npm run check
npm test
```

`HOST` і `PORT` читаються з оточення або `.env` (приклад у `.env.example`).
За замовчуванням сервер слухає `0.0.0.0:3002`.
Перевірка доступності: `GET /api/health`. API описаний у `API.md`.

Docker image збирається тільки з цього каталогу.

Дані зберігаються в пам'яті процесу та втрачаються після перезапуску.
Збережено демонстраційні замовлення, генерацію історії та поточну логіку
аналітики. Авторизація, валідація та реальні платежі ще не реалізовані.
